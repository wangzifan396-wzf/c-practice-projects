# C Practice Projects

这是一个 C 语言和 Visual Studio 练习项目集合，保留了原始练习目录结构，方便回看不同日期的练习代码。

## Contents

- `Project1/`、`Project2/`：Visual Studio 练习工程。
- `test_1_25/`、`test_1_25_2/`、`test_1_26/`、`test_1_28/`、`test_1_29/`：按日期保存的 C 语言基础练习。

## Notes

仓库只保留源码、解决方案文件和工程配置文件。Visual Studio 的 `.vs` 缓存、Copilot/IDE 本地状态、`Debug`/`Release`/`x64` 编译输出、`.exe`、`.obj`、`.pdb` 等文件不会提交。

可以用 Visual Studio 打开对应目录下的 `.slnx` 文件查看和编译，也可以直接阅读各项目目录里的 `.c` 源码。
